Saisie des scores

Apprenez à utiliser l'interface de notation et à comprendre les codes des armes disponibles.

Interface de notation

Une fois votre session démarrée, vous verrez l'écran de notation avec :

La volée en cours

Vous verrez les scores des flèches pour la cible actuelle. Vous pouvez cliquer sur la gomme pour corriger une erreur de saisie.

L'interface de saisie

Il vous permet de saisir les scores pour chaque flèche. Les codes couleurs vous permettent de voir les volées réussies.

Historique en direct

Affiche l'ensemble des volées de votre session. Les scores sont modifiables ou supprimables à tout moment.

Exercice Score cible

L'exercice Score cible utilise une popin de saisie dédiée. En haut, trois cadres affichent :

  • Score : le total des scores déjà saisis dans l'historique.
  • Progression : le rapport entre le score actuel et le score cible.
  • Cible : la cible actuellement tirée.

L'historique est présenté du plus récent au plus ancien. Le bloc de saisie reste accessible en bas de la popin et la saisie s'arrête automatiquement lorsque le score cible est atteint ou dépassé.

Le nombre de cibles du parcours sert à calculer le score cible, mais il ne bloque pas la saisie : si l'objectif n'est pas atteint, vous pouvez continuer sur les cibles suivantes.

Mode duel contre Paquito

En Mode Multi, saisissez Paquito comme deuxième archer pour activer le bot. Un slider permet de choisir son niveau.

  • Pro : Paquito ne tire pas de flèche sous 5 points.
  • Expert : Paquito peut faire une paille, mais jamais une double paille sur la même cible.
  • Élite : Paquito ne tire pas de flèche sous 8 points.

Points possibles selon le parcours

Les points disponibles dépendent du parcours choisi :

Parcours FFTA

  • Campagne : 6, 5, 4, 3, 2, 1, 0
  • 3D : 11, 10, 8, 5, 0

Parcours FFTL

  • 3D Two Shoots : 10, 8, 5, 0
