Saisie des scores

Apprenez à utiliser l'interface de notation et à comprendre les codes des armes disponibles.

Interface de notation

Une fois votre session démarrée, vous verrez l'écran de notation avec :

Sélecteur de cible

Navigation rapide pour accéder à la cible souhaitée. Permet de sauter d'une cible à l'autre facilement.

Sélecteur d'arme

Affiche le type d'arme utilisé pour la cible actuelle. Le menu dépend du parcours choisi.

Historique en direct

Affiche les flèches saisies pour la cible actuelle et permet de corriger les erreurs.

Conseils de saisie rapide

  • Correction : Cliquez sur une flèche dans l'historique pour la corriger
  • Navigation : Utilisez « Précédent » et « Suivant » pour naviguer entre les cibles
  • Sauvegarde automatique : Chaque score est sauvegardé automatiquement

Points possibles selon le parcours

Les points disponibles dépendent du parcours choisi :

Parcours FFTA

  • Nature : 20, 15, 10, 0
  • Campagne : 6, 5, 4, 3, 2, 1, 0
  • 3D : 11, 10, 8, 5, 0

Parcours FFTL

  • 3D Two Shoots : 10, 8, 5, 0
  • 3D Hunting : 20, 16, 10
  • Animal Round : 20, 18, 16, 14, 12, 10, 0
  • Field / Hunter : 5, 4, 3, 0

⚠️ Important : Vérifiez toujours que vous saisissez le bon score. Les erreurs peuvent être corrigées via l'historique des flèches.
