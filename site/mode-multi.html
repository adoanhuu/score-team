Mode Multi

Le Mode Multi regroupe les modes pensés pour tirer à plusieurs, suivre un duel ou simuler un adversaire. Il se choisit lors de la création d'une nouvelle session.

Duel

Le duel met deux archers face à face sur une même session. Chaque archer conserve son historique et son total, ce qui permet de suivre l'écart cible après cible.

Peloton

Le peloton sert à saisir les scores de plusieurs archers sur une interface commune. Il est adapté aux groupes qui avancent ensemble sur le parcours.

Concours

Le mode concours permet de rejoindre ou de suivre une session de concours. Il facilite la saisie collective et le suivi d'une session partagée.

Paquito

Paquito est le bot du mode duel. Il joue le rôle du deuxième archer et son niveau se règle avec un slider pour adapter la difficulté.

Duel contre Paquito

Pour activer Paquito, créez un duel et utilisez Paquito comme deuxième archer. Le bot tire automatiquement selon le niveau choisi.

  • Pro : aucune flèche sous 5 points.
  • Expert : jamais de double paille sur une même cible.
  • Élite : aucune flèche sous 8 points.

Quand utiliser chaque item ?

  • Duel : pour comparer deux archers ou créer une opposition directe.
  • Peloton : pour noter un groupe complet qui tire sur le même parcours.
  • Concours : pour une session organisée ou partagée avec d'autres participants.
  • Paquito : pour s'entraîner seul avec un adversaire virtuel.

Conseil : Si vous hésitez, commencez par Duel pour deux archers, ou Peloton dès que le groupe contient plus de deux tireurs.
