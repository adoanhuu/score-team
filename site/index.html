Bienvenue dans Capi Scoring

Capi Scoring est une application web conçue pour simplifier la gestion des scores lors des parcours de tir à l'arc.

Fonctionnalités principales

Créer une session

Démarrez une nouvelle session en sélectionnant le parcours, l'arme, puis le mode (Mode solo ou Mode Multi).

Mode Multi

Gérez les séances à plusieurs avec des vues adaptées aux tirs collectifs.

  • Duel : deux archers face à face, avec historique séparé.
  • Peloton : jusqu'à six archers sur une saisie partagée.
  • Concours : rejoindre ou suivre une session de concours.
  • Paquito : bot de duel avec niveau réglable.

Capi Scoring se base sur les règlements de la FFTA (Fédération Française de Tir à l'Arc) et de la FFTL (Fédération Field de Tir Libre). L'application fonctionne hors ligne grâce à la technologie de PWA (Progressive Web Apps).

La tuile Entraînement donne accès à des exercices autonomes, dont Score cible pour tirer jusqu'à atteindre un objectif de points.
