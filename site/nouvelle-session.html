Créer une nouvelle session

Découvrez comment configurer une nouvelle session de notation pour votre parcours de tir à l'arc.

Étape 1 : Choisir votre parcours

La première étape consiste à sélectionner le type de parcours que vous allez tirer. Archery Team Score supporte plusieurs parcours selon votre fédération :

Parcours FFTA (Fédération Française de Tir à l'Arc)

Nom du parcours Description
Nature (20 / 15 / 10) Parcours nature classique avec 3 zones de scoring
Campagne (6 / 5 / 4 / 3 / 2 / 1) Parcours campagne avec 6 zones de scoring
3D (11 / 10 / 8 / 5) Parcours 3D avec cibles en relief

Parcours FFTL (Fédération Française de Tir sur Loisir)

Nom du parcours Description
3D Two Shoots (10 / 8 / 5) Parcours 3D avec deux tirs par cible
3D Hunting (20 / 16 / 10) Parcours 3D style chasse
Animal Rounds (3 flèches) Parcours animaux avec 3 flèches par cible
Field / Hunter (5 / 4 / 3) Parcours Field avec 3 zones

Étape 2 : Zone de réussite

Définissez la zone de réussite. Cette valeur établit votre objectif de score minimum pour atteindre votre objectif de progression. Les scores en dessous de ce seuil seront mises en évidence différemment.

Étape 3 : Mode de parcours

Choisissez entre deux modes :

  • Mode Équipe : Enregistrez les scores collectifs de votre équipe
  • Mode Individuel : Suivez les scores individuels de chaque archer

Étape 4 : Type d'arme

Selon le parcours sélectionné, vous devrez choisir le type d'arme utilisé. Cela affecte les options disponibles pour votre session.

Étape 5 : Activation ou non des catégories de cibles

L'option "Utiliser les catégories de cibles" vous permet de trier les cibles dans le formulaire de notation. Activez cette option si vous souhaitez avoir des statistiques affinées par catégorie de cibles.

Démarrage

Une fois tous les paramètres configurés, cliquez sur le bouton « Démarrer » pour commencer à saisir vos scores. Vous arriverez alors à l'écran de notation.

💡 Conseil : L'application sauvegarde automatiquement votre session. Vous pouvez donc quitter et revenir plus tard sans perdre vos données.
