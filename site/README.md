# Site d'aide - Archery Team Score

Ce répertoire contient les pages d'aide et de documentation pour l'application Archery Team Score.

## 📋 Pages disponibles

### 1. **index.html** - Accueil

Page de présentation générale de l'application avec liens vers les autres pages.
Inclut désormais l'accès au mode Entraînement.

### 2. **nouvelle-session.html** - Créer une nouvelle session

Guide détaillé pour :

- Choisir le parcours FFTA ou FFTL
- Configurer le nombre de cibles
- Définir la zone de succès
- Sélectionner le mode d'équipe ou Mode solo
- Utiliser le mode Entraînement, dont l'exercice Score cible
- Tableau comparatif des parcours disponibles

### 3. **saisie-scores.html** - Saisie des scores

Documentation sur :

- L'interface de notation
- **Codes des armes FFTA** : AC, AD, BB, CL, CO, TL
- **Codes des armes FFTL** : BB-C, BB-R, BH-C, BH-R, BL, BU, FS-R, FS-C, FU, HB, LB, TR
- Conseils pour une saisie rapide
- Points possibles selon le parcours
- Exercice Score cible et progression vers l'objectif
- Mode duel contre Paquito et règles par niveau

### 4. **statistiques.html** - Lire les statistiques

Guide complet pour :

- Comprendre les différents onglets de statistiques
- Interpréter les diagrammes
- Analyser l'évolution pendant la session
- Utiliser l'historique des sessions
- Conseils d'analyse de performance

## 🎨 Styles

- **shared.css** : Feuille de styles partagée
  - Variables de couleur cohérentes avec l'application main
  - Design responsive (mobile-first)
  - Composants réutilisables (cartes, tableaux, etc.)

## ⚙️ JavaScript

- **shared.js** : Script partagé
  - Gestion du menu responsive
  - Marquage du lien actif
  - Fermeture automatique du menu

## 🎯 Structure

Toutes les pages partagent :

- Une en-tête commune avec le logo et la navigation
- Un pied de page unifié
- Les mêmes couleurs et styles
- Un menu responsive pour les appareils mobiles

## 🚀 Utilisation

1. Ouvrez `index.html` pour accéder à la page d'accueil
2. Utilisez la navigation pour aller vers les pages souhaitées
3. Le menu est automatiquement responsive sur mobile/tablette

## 📱 Responsive Design

Le site est conçu pour être entièrement responsive :

- **Desktop** : Navigation horizontale fixe
- **Tablet** : Menu avec hamburger optionnel
- **Mobile** : Menu hamburger complet

## 🎨 Cohérence avec l'app

Le site utilise :

- Les mêmes couleurs que l'application principal
- Les mêmes icônes SVG
- La même typographie (Nunito)
- Les mêmes principes de design
